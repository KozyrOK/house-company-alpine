# AI Chat Specification

This directory contains the complete specification for implementing the AI-powered chat using Laravel 13 AI SDK.

The specification is divided into several independent documents.

Read them in the following order:

1. 01-project.md
2. 02-chat-frontend.md
3. 03-assistant.md
4. 04-architecture.md
5. 05-file-structure.md
6. 06-stages.md

Every document is mandatory.

Do not ignore or override requirements from any document.

If two requirements appear to overlap, satisfy both whenever possible.

If a conflict is unavoidable, prefer the more specific requirement.

Follow Laravel 13 and Laravel AI SDK best practices throughout the implementation.
